<p align="center">
  <b>Капри</b> — голосовой ассистент в стиле киберпанка. Живёт поверх окон, появляется с глитч-вспышками,<br>
  слушает команды, управляет компьютером и общается с помощью локальной нейросети.
</p>

> **О проекте.** Это кастомная, Open-Source сборка Капри. В отличие от официальной
> платной версии, здесь есть локальный ИИ (через LM Studio), RPG-система и магазин
> скинов. Ядро полностью переписано на **Rust**: один `capri.exe` на 6 МБ, без Python,
> PySide6 и виртуальных окружений. Старый Python-прототип из репозитория удалён —
> его история осталась в коммитах.

---

## ✨ Что умеет (Особенности)

| | |
|---|---|
| **Локальный ИИ** | Интеграция с **LM Studio**. Никаких API-ключей, работает полностью офлайн. |
| **Голос** | Синтез речи через Edge TTS с запасным голосом Windows (SAPI). Распознавание — **Vosk** офлайн, плюс Google как резерв. |
| **Управление ПК** | Открытие программ, сайтов и видео, поиск в Google и на YouTube, управление окнами, громкостью, яркостью, медиаплеером. |
| **RPG и Экономика** | Уровни, опыт (XP), внутриигровая валюта ($). Зарабатывайте деньги, выполняя команды. |
| **Магазин скинов** | Скины (Неон, Токсин, Лёд и др.), меняющие цвет Капри. Купленный скин надевается сразу. |
| **Память** | «Запомни, что…» и «что ты помнишь про…» — факты сохраняются между запусками. |
| **Характер** | Своя персона, глитч-озвучка, болтовня, реакция на время суток, меню в трее. |
| **Окно** | Слоистое окно поверх всех: перетаскивается мышью, гуляет по экрану, машет, прячется. |

> **Работает и без ИИ, и без слуха** — без модели Vosk Капри честно скажет «Я тебя не слышу»,
> а окно, голос и меню продолжат работать.

## 🚀 Установка

**Нужно:** Windows 10 или 11, микрофон, интернет для голоса (Edge TTS).

### 1. Скачай проект
Зелёная кнопка **Code → Download ZIP** вверху страницы. **Распакуй** архив в удобную папку
(например, `Документы\capri`). Из архива запускать нельзя.

Внутри уже лежит собранный `capri.exe` — компилировать ничего не нужно.

### 2. Положи модель распознавания речи
Скачай модель с [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models)
(нужна `vosk-model-small-ru-0.22`) и распакуй в папку `models\` рядом с `capri.exe`.
Проверка: существует файл `models\vosk-model-small-ru-0.22\am\final.mdl`.

### 3. Положи библиотеку Vosk
Скачай `vosk-win64-*.zip` из [релизов vosk-api](https://github.com/alphacep/vosk-api/releases)
и вытащи `libvosk.dll` в папку с `capri.exe`.

Без шагов 2–3 Капри запустится, но не будет слышать.

### 4. Настрой локальный ИИ (LM Studio)
1. Скачай и установи [LM Studio](https://lmstudio.ai/).
2. Скачай любую модель (например, **Qwen2.5-3B-Instruct** для слабых ПК или **Qwen2.5-7B-Instruct** для мощных).
3. Перейди во вкладку **Local Server** и нажми **Start Server** (порт должен быть `1234`).
4. В файле `config.json` пропиши название вашей модели в строке `"local_model": "имя-модели"`.

### 5. Запусти capri.exe
Капри появится и поздоровается. Кликни по ней **правой кнопкой** — откроется меню команд.
Правый клик по иконке в трее открывает то же меню.

### Сборка из исходников (если хочется)
Нужен Rust с [rustup.rs](https://rustup.rs). Затем `build-rust.bat` в корне проекта — он
проверит, прогонит тесты и соберёт `capri.exe`. Либо вручную:

```bat
cd capri-rs
cargo build --release
```

## 🛠️ Настройка (config.json)

Все настройки хранятся в `config.json` рядом с `capri.exe`. Файл перечитывается на каждой
команде, так что править можно на ходу.

| Ключ | Что значит |
|---|---|
| `local_model` | Название модели в LM Studio (например, `qwen2.5-3b-instruct`). |
| `tts_engine` | Движок озвучки: `"edge"` (облачный, красивый) или `"sapi"` (голос Windows, офлайн). |
| `voice_volume` | Громкость 0…100. Значение `0` считается как «не задано» — Капри скажет на 100. |
| `voice_fx` | Сила цифровых эффектов голоса (`0` — чистый, `1.8` — сильный глитч). |
| `voice_shift` | Насколько поднимать тон, полутона. |
| `wake_words` | Слова, на которые Капри откликается. |
| `barge_in` | Можно ли перебивать Капри голосом (`true`/`false`). |
| `chatter` | Появляется ли она сама время от времени (`true`/`false`). |
| `mic_device` | Имя микрофона, `null` — системный. |

Скины: `purple`, `neon`, `red`, `ice`, `toxic`, `sunset`. Прогресс, деньги и уровни — в
`save_data.json` рядом с `capri.exe`.

Полный список голосовых команд — в [КОМАНДЫ.md](КОМАНДЫ.md).

## 📂 Структура проекта

```
capricorn-main/
├── capri.exe          собранная программа
├── config.json        настройки
├── save_data.json     прогресс, деньги, скины
├── assets/            спрайты и анимации Капри
├── models/            модель Vosk
├── run-rust.bat       запустить
├── build-rust.bat     проверить, протестировать и собрать
├── КОМАНДЫ.md         что можно сказать
├── BUGS.md            разбор старого Python-прототипа
└── capri-rs/          исходники
    └── crates/
        ├── core/    настройки, персона, разбор команд, индекс программ, нейросеть
        ├── win/     всё, что обращается к Windows (Win32 вызывается только здесь)
        ├── voice/   микрофон, распознавание, синтез, воспроизведение
        ├── ui/      окно аватара, подпись, меню в трее
        └── app/     связка всего этого, точка входа
```

Ядро `core` не знает про Windows: любая системная возможность описана методом типажа
`capri_core::platform::Platform`. Поэтому разбор команд покрыт тестами и проверяется без
запуска программы. Тесты: `cargo test --workspace` — 64 штуки.

## ❓ Частые проблемы

| Проблема | Что делать |
|---|---|
| **Не слышит, говорит «Я тебя не слышу»** | Нет `libvosk.dll` или модели в `models\`. Смотри шаги 2–3. |
| **ИИ не отвечает** | Проверьте, запущен ли сервер в LM Studio и нажата ли «Start Server». Проверьте `local_model` в `config.json`. |
| **Голос молчит** | Смотрите `capri.log`. Если там `voice_volume = 0` — выставьте громкость в настройках. |
| **В логе «edge-tts недоступен (403)»** | Сервис Edge TTS блокирует запросы. Это не поломка: Капри сама переходит на голос Windows. |
| **Меню не закрывается** | Обновите `capri.exe` — в старых сборках правый клик вешал окно. |
| **Не запускается, ругается на DLL** | Поставьте [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe). |

Логи пишутся в `capri.log` рядом с `config.json`. Запуск `capri.exe --console` дублирует их на экран.
